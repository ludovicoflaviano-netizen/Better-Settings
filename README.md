# Better Settings

Better Settings is a Paper 1.21.11 personal-settings plugin built around Paper's native Dialog API. It is designed for SMP servers with a clean, Donut-style settings flow without using a chest inventory GUI.

## Commands

- `/bettersettings` — open the native settings screen
- `/bettersettings open` — open the same screen
- `/bettersettings <category>` — open a category directly
- `/settings` and `/bsettings` and `/bs` — aliases
- `/bettersettings reload` — reload config (admin permission)

## Features

- 121 per-player toggleable settings
- Native Paper Dialog UI with category/item icons
- Gameplay, Combat, Movement, Visual, Chat, Items, World and Utility categories
- Personal settings stored per UUID
- Silent spawn option
- Join/quit message controls
- Personal potion/effect preferences
- Permission support
- Paper 1.21.11 / Java 21
- GitHub Actions build

Paper Dialogs are a native in-game menu API introduced in Minecraft 1.21.6 and exposed by Paper from 1.21.7 onward.
